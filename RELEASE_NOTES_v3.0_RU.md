# ROB RUN Atlas v3.0

Интерактивная карта Лути-Бей в стиле интерфейса игры. Теперь в ней только локации.

## Что нового

- Оформление под меню ROB RUN: узкий жирный курсив капсом (Fira Sans Extra Condensed, Roboto Condensed), тёмно-серые панели, салатовый акцент, скошенные кнопки и вкладки, острые углы. Число локаций показано в ромбе, как статистика клана.
- Остался один режим — локации. Убраны вкладка «Точки карты», фильтры категорий точек, панель «Мой заход» и отметки «обыскано».
- Убран каталог предметов: для предметов будет отдельная вики.
- Карточка локации: описание, «Можно найти» (4 предмета), подсказка про ключи и сейфы, блок «Закрытые зоны и сейфы» (ключ, число больших сейфов, мини-буры). Убраны плашки категорий, «Лут на известных точках», «Случайный лут по категориям» и ссылки на точки.
- Карточка предмета открывается без списков точек и кнопок «на карте».

Данные и база не менялись: Playtest build 26342425, 28 локаций.

## Новые и изменённые файлы

dist/index.html, dist/style.css, dist/app.js и новый dist/theme-game.css. Старый код точек отключён, а не удалён, поэтому его легко вернуть.

## Запуск

Node.js 22+:

    node scripts/serve.mjs

Откройте http://localhost:3000. Шрифты загружаются с Google Fonts; без интернета используется похожий системный шрифт.
