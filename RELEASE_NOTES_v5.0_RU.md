# ROB RUN Atlas · v5.0

Рабочая версия карты после полной проверки карточек локаций по данным сцены и базы (robrun_wiki, build 26342425).

## Что изменилось

### Банк — исправлено
- **Дверь хранилища (бур)** открывает хранилище: 3 банковских сейфа, наличные и 12 банковских ячеек.
- **Дверь по ID-карте** находится внутри хранилища, поэтому сначала нужен бур. За ней только 7 золотых слитков, сейфов нет, мини-буры не нужны.
- Разделение сделано по координатам точек в сцене, а не по ближайшей двери.

### Запертые комнаты во всех локациях
- В состав комнаты теперь попадают все сейфы (точки, которые вскрываются мини-буром) и компьютеры, даже если в данных у них нет метки комнаты. Например, сейфы магазина снаряжения раньше не отображались.
- В строке «За дверью» показываются банковские ячейки и компьютеры для взлома.
- Если в комнате есть компьютеры, показывается кликабельная флешка с суммой очков, которые можно набрать.

### Новый блок «Заполняется здесь»
- В карточке каждой локации показано, какие заполняемые предметы можно прокачать именно здесь и сколько очков дают: флешка (взлом компьютеров), планшет (вскрытие сейфов), экшн-камера (криминальные действия), ключ от ячеек (взлом банковских ячеек).

### Проверка
- Автоматическая проверка двери, сейфов, компьютеров и мини-сейфов: 28 из 28 локаций совпадают с данными.

## Известный вопрос
- Магазин снаряжения: 2 сейфа стоят примерно в 7 м от двери комнаты, с другой стороны. Сейчас они показаны как находящиеся за дверью по ключу. Если в игре это не так, поправим в следующей версии.
