# ROB RUN — интерактивный атлас лута

Релиз v0.2: карта, 506 предметов, 926 точек, Бартер и раскрывающиеся цепочки получения. Карточки локаций показывают ключи к закрытым зонам, количество больших сейфов и комплект мини-буров. Подробности: [RELEASE_NOTES_v0.2_RU.md](RELEASE_NOTES_v0.2_RU.md).

**Начните с [HANDOFF_RU.md](HANDOFF_RU.md).** Готовое задание для следующего ИИ: [CONTINUE_PROMPT_RU.md](CONTINUE_PROMPT_RU.md).

## Запуск

Нужен Node.js 22 или новее. Внешних npm-зависимостей нет.

```sh
npm run build
npm start
```

Откройте http://localhost:3000. Порт задаётся переменной `PORT`.

Для статического хостинга: команда сборки `npm run build`, каталог публикации `dist`. Подготовлены также `Dockerfile` и `netlify.toml`. Проверка: `npm run check`.

Ассеты хранятся сжатыми частями в `resources/`. Сборка проверяет SHA256 и автоматически распаковывает их. Установка дополнительных пакетов и доступ к исходному сайту не нужны.

## Состояние проекта

- 506 предметов проверены: у 235 найден хотя бы один подтверждённый источник, у 271 источник пока неизвестен. Все пути ещё не завершены.
- 208 контейнеров с типами и условиями вскрытия, 20 дверей доступа, 16 компьютеров.
- Девять правил заполнения накопительных предметов и 11 рецептов Бартера.
- Все оригинальные иконки, восстановленная карта, полный аудит, исследовательские материалы и декодеры сохранены.
- Подсказки игровой карты отделены от доказанных источников. Пулы и вероятности не заполняются догадками.

Код приложения: `dist/app.js`, `dist/style.css`, `dist/index.html`. Данные: `dist/data.js` и `dist/db.js`, они собираются из базы.

## База данных

Источник данных атласа — база Supabase, схема `robrun_wiki`. После изменений в базе пересоберите атлас:

```sh
npm run db:build
```

Команда заново создаёт `dist/data.js` и `dist/db.js` и запускает `npm run check`. Нужны `.venv` с пакетами из `research-requirements.txt` и строка `SUPABASE_DB_URL` в `.env`. База только читается. Если данные неполные, сборка останавливается и прежние файлы не меняются. Что изменилось: [docs/DB_BUILD_REPORT_RU.md](docs/DB_BUILD_REPORT_RU.md).

Сайту база во время работы не нужна: `npm run build` и хостинг используют уже собранные файлы из `dist/`. Не правьте `dist/data.js` и `dist/db.js` вручную.

Новому предмету нужна иконка в `dist/assets/items`, а новой точке — заполненные `map_px` и `map_py`. Каталог `dist/assets/` не хранится в git, поэтому новую иконку нужно также добавить в архив `resources/assets`.

## Исследовательские материалы

```sh
npm run research:unpack
```

Команда распакует `work/` со скриптами и `outputs/rob-run-research/` с результатами. Для запуска приложения это не требуется. Python-зависимости перечислены в `research-requirements.txt`.

Данные относятся к Steam build `26342425`. SHA256 публичного `references.dat`: `281754339c0ec25be744e136782d89d05dcda7db0b7b2115b39dfd6d8f533c4f`.

Исходная публикация: https://rob-run-loot-atlas.poznergpt.chatgpt.site — она управляется отдельным аккаунтом. Этот репозиторий разворачивается самостоятельно и не содержит её учётных данных.
