# ROB RUN · Интерактивная карта · v5.4

## Что изменилось

### Гранд-отель: угон выставочного автомобиля — на карте
- В карточке Гранд-отеля блок «Угон выставочного автомобиля»: Джеммер → Buletti Soltempra, 4 шага (найти консоль; установка 3 с; взлом 60 с; взятие 2 с).
- В карточке Buletti Soltempra — «Как получить», в карточке джеммера — «Применение».
- Маршрут вписан в `dist/data.js` (то же содержание, что в `docs/sql/route_buletti_exhibition_car.sql`). **Важно:** пока этот SQL не выполнен в Supabase, `npm run db:build` уберёт маршрут из `dist/data.js`. После выполнения SQL пересборка оставит его на месте.

### Карточки предметов
- «Как получить» больше не показывает сам предмет как «Что можно получить» — только то, что нужно, и шаги.
- «Применение» не показывает сам предмет среди нужного: остальное — «Ещё понадобится», затем результат.
- Убраны кнопки «Показать на карте» в карточках предметов.
- Убрана подпись «Открыть способ получения» у патронов в карточке оружия.
- Убраны блоки «Исходные значения оружия» и «Исходные значения брони».
