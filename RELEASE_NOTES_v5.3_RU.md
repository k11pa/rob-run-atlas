# ROB RUN · Интерактивная карта · v5.3

## Что изменилось

### Активности в локациях
- Особый лут теперь показан отдельным блоком **«Активность в локации»**: кликабельные карточки с картинками «Что потребуется → Что можно получить» и шаги.
- Арт-галерея: «Экспонат в Арт-галерее» — Стеклорез → BIG EGG #53.

### Карточки предметов
- У предметов с маршрутом появился раздел **«Как получить»** (цепочка, шаги, кнопка «Показать на карте»).
- У предметов, которые нужны для маршрута, — раздел **«Применение»** (например, стеклорез, бур, ID-карта).
- Предупреждения на предметах:
  - **Джеммер:** когда начинается взлом консоли в Гранд-отеле, об этом узнаёт весь город;
  - **Бур:** когда начинается вскрытие двери хранилища в банке, об этом узнаёт весь город.

### Гранд-отель: угон выставочного автомобиля (подготовлено)
- Джеммер → Buletti Soltempra: найти консоль, установка 3 с, взлом 60 с, взятие 2 с.
- Подготовлен импорт в базу: `docs/sql/route_buletti_exhibition_car.sql`. **В базе ещё не применён**, поэтому на карте блок появится после выполнения SQL и `npm run db:build`.
- Подробности и что не установлено: `docs/audits/GRAND_HOTEL_BULETTI_RU.md`.

### Исправлено
- На телефоне карточка локации сжималась до узкой полосы (56 px): боковая панель занимала место в разметке. Исправлено.
