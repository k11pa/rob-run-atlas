Продолжи разработку интерактивного атласа ROB RUN.

Прочитай AGENTS.md, README.md, HANDOFF_RU.md и верхнюю часть docs/ROB_RUN_CHECKPOINT_RU.md. Запусти npm run build и npm run check. Для исследования выполни npm run research:unpack.

Нужно довести способы получения предметов ОТ и ДО: все источники, ингредиенты, ключи, двери, инструменты, покупка, открытие дерева торговца и накопительные предметы. Пользователь недоволен обрывами цепочек. Проверены все 506 позиций: у 235 есть хотя бы один источник, у 271 источник пока неизвестен. Не заполняй пробелы догадками и не называй частичный путь завершённым.

Сохрани текущий дизайн и восстановленные данные. Приоритеты: источники оставшихся предметов и случайные лутпулы, точная привязка комнат к дверям, условия открытия товаров. В свежем handoff исправлены ошибки исторических отчётов: источник банковской ID-карты уже известен. Не ставь выдуманную метку входа в хаб на городской карте.
