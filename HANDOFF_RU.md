# Начать здесь

**Обновление:** источник данных теперь база Supabase (схема `robrun_wiki`). `dist/data.js` и `dist/db.js` создаёт `npm run db:build`, см. README. Раздел «Сборка данных» ниже относится к прежним скриптам и больше не актуален для обновления атласа.

Это полная передача работающей версии 6 другому разработчику. Публикация в Public явно разрешена владельцем 2 ноября 2026 года; упоминания приватной передачи в исторических заметках относятся к более раннему плану.

1. Запустите `npm run build`, `npm run check`, затем `npm start`.
2. Для исходных исследовательских материалов выполните `npm run research:unpack`.
3. Основной код находится в `dist/`; контрольная точка — `docs/ROB_RUN_CHECKPOINT_RU.md`, самая свежая v6 расположена сверху.
4. Полный аудит 506 предметов — `docs/ROB_RUN_ITEM_ACQUISITION_AUDIT_RU.md`.

**Задача не завершена:** нужны все пути получения каждого предмета, включая ингредиенты, покупку, заполнение, ключи, двери и инструменты. У 235 предметов есть хотя бы один источник, у 271 источник пока не восстановлен. Это не 235 полностью проверенных маршрутов: некоторые условия доступа ещё неизвестны.

Ключевой пример уже исправлен: незаполненные банковские ключи покупаются в ноутбуке при тире III; нужно носить их с собой и накопить 60 очков взломом подходящих ячеек. Есть 12 точек по +1 очку. Заполненные ключи обмениваются в Бартере на ID-карту золотохранилища. ID рецепта `vip_key_2`, результат `vip_key_5` — эти идентификаторы различаются.

Не придумывайте отсутствующие лутпулы, вероятности и связи комнат с дверями. Не переносите локальную метку Бартера из отдельной сцены хаба на городскую карту. Точное положение входа в хаб относительно города ещё не установлено.

Продолжайте работу в этом репозитории и разворачивайте отдельный сайт. Исходная публикация Sites принадлежит другому аккаунту. Игровые бинарники, сервисный public-config.json и учётные данные не передавались.

Ниже — подробная техническая передача. В исторических заметках сохранены прежние пути и версии скриптов; готовый `dist/data.js` является актуальным набором данных.
