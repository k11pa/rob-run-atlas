# ROB RUN Atlas v4.0

Карта Лути-Бей в стиле интерфейса игры: только локации.

## Что изменилось с v3.1

- В карточке каждой локации появился блок «Закрытые комнаты и сейфы». Для каждой двери показаны ключ, ключ-карта или бур (кликабельные), количество больших сейфов, нужное число мини-буров (с картинкой) и шкафы. Ниже идёт «Внутри можно найти»: компактный список предметов от дорогого к дешёвому и метки случайного лута. Отдельно показаны малые сейфы, которые открываются зелёным ключом.
- Содержимое комнат взято из данных сцены игры. Полицейский участок исправлен по опыту игроков: сейфы и лут комнаты находятся за ключ-картой, а за ID-картой выпадает LM 249 Mk2. Источник пулемёта в базе пока не указан.
- Карта: размер иконок зависит от зума. Перекрывающиеся иконки раздвигаются, к реальному месту ведёт тонкая линия. Подписи ищут свободное место (снизу, сверху, сбоку) и не перекрывают друг друга.
- Подсказка «Цена продажи» всплывает над карточкой предмета или рядом с ней и больше не растягивает карточку.
- Убрана надпись PLAYTEST.

## Запуск

К релизу приложен архив rob-run-atlas-v4.0.zip со всем проектом. Распакуйте его и запустите (Node.js 22+):

    npm start

Затем откройте http://localhost:3000. Шрифты загружаются с Google Fonts.

Данные: Playtest build 26342425, 28 локаций.
