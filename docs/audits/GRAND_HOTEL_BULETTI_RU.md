# Гранд-отель: угон выставочного автомобиля → Buletti Soltempra

Статус: **импорт подготовлен, в базе ещё не применён.** Карточки на карте появятся после двух шагов:

1. выполнить `docs/sql/route_buletti_exhibition_car.sql` в Supabase (схема `robrun_wiki`, SQL editor);
2. `npm run db:build`, затем `npm run check`.

`dist/data.js` и `dist/db.js` вручную не менялись.

## Что делает импорт

Добавляет только новые строки, существующие не трогает. Повторный запуск ничего не дублирует, потому что все вставки идут через `on conflict (slug) do nothing`.

| Таблица | Что добавляется |
|---|---|
| `source_kinds` | `game-files` — файлы установленной игры, если такой строки ещё нет |
| `sources` | `game-files-26377677-buletti` — описание доказательств сборки 26377677 |
| `acquisition_routes` | `grand_hotel_exhibition_car` для `buletti_soltempra`, контрольная точка — существующая точка лута 795 `GrandHotel/Loot/LootObjectSet/buletti` |
| `route_required_items` | `auto_flipper_1` (Джеммер) |
| `route_steps` | 4 шага: найти консоль; установка 3 с; взлом 60 с; взятие 2 с |
| `route_step_items`, `route_step_points` | джеммер в шаге 2, точка 795 в шаге 4 |
| `route_evidence_lines` | 5 строк доказательств, на английском, как у маршрута яйца Фаберже |

Новых координат нет. Используется точка 795, которая уже есть в базе и уже привязана к Гранд-отелю. Объект доступа 1683, то есть консоль, на карте отдельной точкой не показывается.

## Что показывает интерфейс (dist/app.js)

Код общий для всех маршрутов `acquisition.routes`. Те же блоки теперь получает и яйцо Фаберже.

- **Карточка локации.** Блок «Активность в локации · {название маршрута}» содержит:
  - кликабельные карточки с картинками «Что потребуется → Что можно получить»;
  - шаги с временами.

  Примечания про полицию, оповещение и статус подтверждения убраны по просьбе владельца: `notes` маршрута = null.
- **Плитка «Можно найти».** На плитке подписано «Нужно: Джеммер».
- **Карточка Buletti Soltempra.** Раздел «Как получить» содержит:
  - цепочку из двух карточек;
  - шаги;
  - кнопку «Показать на карте: Гранд-отель».
- **Предупреждение на предметах** (задано в `dist/app.js`, `itemAlerts`, не из базы):
  - Джеммер: «Когда начинается взлом консоли в Гранд-отеле, об этом узнаёт весь город» (по локализации 530184765817745408);
  - Бур: «Когда начинается вскрытие двери хранилища в банке, об этом узнаёт весь город» (со слов владельца проекта; строки в данных не найдено).
- **Карточка джеммера.** Раздел «Применение» содержит:
  - цепочку и кнопку показа локации;
  - строку «Как получить: Подтверждённый способ получения джеммера пока не установлен».

У других зданий требование джеммера не появляется. Это проверено по всем 28 карточкам локаций в превью.

Попутно исправлено: на ширине телефона (до 780 px) боковая панель занимала место в разметке, и карточка локации сжималась до 56 px. Ошибка появилась вместе с игровой темой, исправлена в `theme-game.css`.

## Не установлено

- Источник джеммера: магазин, бартер, дроп или событие. В базу не добавляется ничего из этого.
- Расходуется ли джеммер и возвращается ли он при прерывании.
- Этаж и путь внутри отеля, ключи от дверей, перезапуск события.
- Как предмет Buletti Soltempra становится машиной, на которой можно ездить.
- Текущие цены. Карточки предметов показывают базовую цену и цену продажи из сборки 26342425: у джеммера 160 000, у Buletti 5 500 000. Для сборки 26377677 эти цены не подтверждены. В новых блоках цены не используются.
