# Карточки локаций: обычный обыск и закрытый лут

## Последующая правка 03.11.2026

По новой просьбе пользователя удалены баннер «Для обычного обыска ключ не нужен» и вступление с этим пояснением в блоке закрытого лута. Предыдущее описание ниже оставлено как история изменения.

Теперь у каждой локации с большими сейфами есть визуальный план: подходящий ключ/ключ-карта/бур двери, количество больших сейфов и необходимое количество мини-буров. Изображения предметов открывают их карточки; список сейфов раскрывается с переходами на карту. Место применения каждого ключа показано в отдельной карточке входа. Подробности получения ключа убраны под раскрытие, чтобы основной текст описывал подготовку к вылазке.

Количество вычисляется из drillAllowed + drillItem=mini_drill_1, а не из общего количества контейнеров: например, галерея — 2, аптеки — 1, оружейные и магазины экипировки — 2, заправка — 3. Привязка конкретной комнаты к количеству сейфов по-прежнему утверждается только для шести подтверждённых пользователем магазинов. В остальных локациях явно написано «В локации», а при нескольких дверях — что это общее количество, без распределения по комнатам. Не приписывать одному ключу автоматически все сейфы локации.

Проверено в браузере: Gallery (ключ-карта + 2 мини-бура), Pharmacy_01 (ключ + 1 мини-бур), GasStation (разные ключи для левой/правой комнат, 3 сейфа всего). GitHub, Supabase и генерируемые data.js/db.js не изменялись.

03.11.2026. Изменения сделаны только в локальной копии test; GitHub и Supabase не изменялись. dist/data.js и dist/db.js не редактировались.

## Основание

Пользователь сообщил из игрового опыта:

- При ограблении любого здания/магазина может случайно выпасть любой зелёный ключ.
- Зелёный ключ ведёт к конкретному малому сейфу. Место применения не является местом выпадения ключа.
- В малом сейфе, открытом зелёным ключом, может выпасть фиолетовый ключ от случайной локации.
- Фиолетовый ключ открывает комнату; большие сейфы внутри требуют мини-буры.
- В оружейных магазинах и магазинах экипировки внутри по 2 больших сейфа: 2 мини-бура; в аптеках по 1: 1 мини-бур.

Это показания игрока, а не извлечённые вероятности. Проценты не задавались. Правило не распространялось на легендарные ключи и ключ-карты.

## Изменения

В начале карточки теперь пояснение «Для обычного обыска ключ не нужен», затем категории и лут. Большие плитки ключей удалены из начала. Ниже расположен блок «Дополнительный лут → Закрытые зоны и сейфы»: компактные ключи с назначением, описанием получения и переходом к конкретной двери/сейфу.

Для WeaponShop_01/02, EquipShop_01/02 и Pharmacy_01/02 показан визуальный комплект: ключ от комнаты ×1 + мини-бур ×2/×1. Данные о числе буримых контейнеров в этих зданиях совпадают с указанными количествами. Принадлежность закрытой комнате помечена как игровой опыт игрока; автоматически переносить эту связь на другие здания нельзя.

Во всех карточках есть раскрывающаяся цепочка зелёный ключ → малый сейф → фиолетовый ключ → комната и большие сейфы. В карточки safe_key_* редкости Uncommon и room_key_* редкости Epic добавлен этот способ получения с пометкой источника. Для room_key_6/13 (Legendary), vip_key_* и остальных предметов такой источник не приписывается.

Кнопка предмета, имеющего только точки применения, теперь называется «Где применяется». Это устраняет путаницу с местом нахождения.

Сведения игрока находятся в app.js (playerRoomSafes, observedKeySource, keyJourney), отдельно от генерируемых данных Supabase. Счётчики подтверждённых источников из БД остаются прежними; сведения игрока не выдаются за новые записи БД.
