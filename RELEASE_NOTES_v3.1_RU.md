# ROB RUN Atlas v3.1

Карта Лути-Бей в стиле интерфейса игры: только локации.

## Что изменилось с v3.0

- «Можно найти» в карточке локации показывает 4 самых дорогих предмета, от дорогого к дешёвому. Источники: витрина игры у здания и предметы, заданные для точек этого здания. Пример: в арт-галерее первым идёт BIG EGG #53 (яйцо Фаберже).
- Поиск убран полностью.
- Убрана зелёная обводка при нажатии на кнопки и списки.
- В карточке предмета осталась только базовая информация: описание, базовая цена, размер, цена продажи, тип и размер стопки. Блоки «Как получить», «Открывает доступ» и «Что ещё не установлено» убраны. Подробности о предметах будут в отдельной вики (кнопка «Ссылка на предмет»).

## Состав v3.0 (сохраняется)

Оформление под меню ROB RUN, один режим «Локации», без каталога предметов, точек карты и отметок «обыскано». Блок «Закрытые зоны и сейфы» в карточках локаций остаётся.

## Запуск

К релизу приложен архив rob-run-atlas-v3.1.zip со всем проектом. Распакуйте его и запустите (Node.js 22+):

    npm start

Затем откройте http://localhost:3000. Готовые файлы сайта лежат в папке dist/, картинки распаковываются из resources/ при первом запуске. Шрифты загружаются с Google Fonts.

Данные: Playtest build 26342425, 28 локаций.
