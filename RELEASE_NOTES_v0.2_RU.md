# ROB RUN Atlas v0.2

Карточки локаций теперь отделяют добычу в здании от подготовки к закрытым комнатам и сейфам. В начале показан лут; ключи находятся в разделе дополнительной добычи, с назначением и переходом к конкретной двери или сейфу.

- Иллюстрированный комплект для больших сейфов: подходящие ключи/ключ-карты, число сейфов и количество мини-буров. Например, галерея — 2, аптека — 1, оружейные магазины и магазины экипировки — 2. Если дверей несколько, число относится ко всей локации; непроверенное распределение по комнатам не утверждается.
- Цепочка зелёный ключ → малый сейф → фиолетовый ключ → закрытая комната. Сведения игрока отмечены отдельно от извлечённых данных; правило не распространено на легендарные ключи и ключ-карты.
- «Где применяется» в карточках ключей отделяет место использования от места получения.
- Исправлено чтение drop_probability из Supabase при сборке связанных точек. Неизвестная вероятность не превращается в 0%; количество за действие и число действий отображаются отдельно.
- Включены результаты аудита источников и локального исследования поставок.

В основе — ветка test с поддержкой сборки из Supabase. База данных при подготовке релиза не изменялась. Сайт работает на уже собранных данных из dist/; при обычном запуске подключение к Supabase не требуется.

## Известные ограничения

Данные карты: Playtest build 26342425, 506 предметов, 926 точек. Подтверждён хотя бы один источник в БД у 235 предметов; у 271 он не восстановлен. Заполненных вероятностей случайного дропа в БД нет. Дополнительное исследование клиента build 26377677 приложено как отчёт, но автоматическое обновление всех данных игры в этот релиз не входило. Полные цепочки доступа местами не установлены. Локальные отметки обыска не синхронизируют персонажа.

## Запуск готового архива

Распакуйте rob-run-atlas-v0.2.zip, перейдите в папку rob-run-atlas-v0.2 и запустите Node.js 22+:

```sh
node scripts/serve.mjs
```

Откройте http://localhost:3000. Для статического хостинга загрузите содержимое dist/. Все изображения уже включены. Секреты, .env и подключение к БД в готовой сборке отсутствуют.

## Проверка

pnpm run build; pnpm run check. В браузере проверены карточки особняка, оружейного магазина, аптеки, галереи и заправки; раскрытие списков, карточки ключей и переход к двери на карте. ZIP проверен по CRC и SHA256 каждого файла.
